SENAC NAÇÕES UNIDAS

1. Introdução ao SpectraWave

02 / 20

O projeto SpectraWave surge como uma ferramenta analítica computacional desenvolvida nativamente para navegadores web. O propósito central do sistema é receber um sinal mecânico ondulatório complexo (arquivo de áudio), isolar suas regiões de máxima densidade energética e realizar o mapeamento completo de seus componentes espectrais.

Ao abdicar inteiramente do uso de bibliotecas matemáticas de alto nível prontas, o código implementa algoritmos de Processamento Digital de Sinais (DSP) puramente baseados em álgebra matemática linear discreta e contínua.

Isso permite estudar a física dos fenômenos ondulatórios diretamente através do fluxo de dados e da computação em tempo real na máquina do usuário.

2. A Natureza do Som e Discretização

03 / 20

O som consiste em oscilações de pressão. Um microfone converte essa pressão em eletricidade e o computador amostra essa variação milhares de vezes por segundo, gerando um vetor bruto no Domínio do Tempo.

No entanto, essa lista sequencial de números não nos revela quais frequências compõem o sinal. Para extrair as "notas puras" escondidas nesse dado, recorremos à teoria formulada por Jean-Baptiste Joseph Fourier.

3. A Série de Fourier Contínua

04 / 20

A premissa é que qualquer oscilação periódica pode ser recriada somando-se infinitas ondas puras de senos e cossenos. A equação trigonométrica base é:

$$f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left[ a_n \cos(2\pi n f_0 t) + b_n \sin(2\pi n f_0 t) \right]$$

4. Elementos da Equação Contínua

05 / 20

Dissecando cada termo da modelagem:

  • $a_0 / 2$: Componente DC. A média aritmética do sinal, indicando se a onda flutua perfeitamente simétrica em torno do zero ou se há um desvio contínuo de eixo.
  • $f_0$: A Frequência Fundamental. A taxa de oscilação mais baixa que define o compasso principal da onda.
  • $a_n$ e $b_n$: Os coeficientes espectrais. São os "pesos" que ditam a intensidade de cada cosseno ($a_n$) e seno ($b_n$) necessária para reconstruir o sinal.

5. Transformada Discreta de Fourier (DFT)

06 / 20

A Série de Fourier exige um sinal infinito e periódico. Na computação, lidamos com recortes finitos de áudio ($N$ amostras discretas, $x[n]$).

Aplicamos a DFT para converter as amostras temporais no vetor complexo de frequências $X[k]$:

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-i \frac{2\pi k n}{N}}$$

6. Identidade de Euler e Rotação

07 / 20

A complexidade da DFT está na exponencial $e^{-i\theta}$. Utilizando a Identidade de Euler, a equação revela seu comportamento geométrico:

$$X[k] = \underbrace{\sum_{n=0}^{N-1} x[n] \cos\left(\frac{2\pi k n}{N}\right)}_{\text{Eixo Real (a)}} - i \underbrace{\sum_{n=0}^{N-1} x[n] \sin\left(\frac{2\pi k n}{N}\right)}_{\text{Eixo Imaginário (b)}}$$

O áudio é multiplicado por ondas de teste na frequência $k$, extraindo componentes reias e imaginárias.

7. A Intuição Geométrica

08 / 20

Imagine que você enrola a linha do gráfico da sua onda sonora ao redor de um círculo com velocidade de rotação ajustável $k$.

  • Se a frequência do áudio não coincidir com a velocidade $k$, cristas e vales se anulam mutuamente. O somatório resulta em zero.
  • Se a frequência do áudio coincidir perfeitamente com a rotação $k$, ocorre ressonância matemática. O centro de massa é deslocado, gerando um vetor de alta magnitude.

8. Magnitude e Fase Espectral

09 / 20

A partir das coordenadas cartesianas ($a$ e $b$) geradas pela DFT, extraímos as propriedades físicas reais da acústica:

$$\text{Magnitude (Força)} = |X[k]| = \sqrt{a^2 + b^2}$$
$$\text{Fase (Atraso)} = \phi_k = \arctan\left(\frac{b}{a}\right)$$

O resultado é convertido para notação polar: $X[k] = |X|e^{i\phi}$.

10. Engenharia: FFT Radix-2 (Bit Reversal)

11 / 20

A equação bruta demanda $O(N^2)$. Para o navegador suportar o cálculo, o \texttt{fft.js} aplica a FFT de Cooley-Tukey.

O primeiro passo é reordenar a memória separando índices pares e ímpares sistematicamente:

let j = 0; for (let i = 1; i < n; i++) { let bit = n >> 1; while (j & bit) { j ^= bit; bit >>= 1; } j ^= bit; if (i < j) { // Inversão espelhada (Bit Reversal) [real[i], real[j]] = [real[j], real[i]]; [imag[i], imag[j]] = [imag[j], imag[i]]; } }

11. Engenharia: Estágio de Borboletas

12 / 20

Após a reordenação, o algoritmo executa o laço de Borboleta (\textit{Butterfly Stage}).

Subfatias de dados são multiplicadas por fatores de giro (senos e cossenos), reduzindo a complexidade para $O(N \log N)$.

const tReal = wReal * real[idxB] - wImag * imag[idxB]; const tImag = wReal * imag[idxB] + wImag * real[idxB]; real[idxB] = real[idxA] - tReal; imag[idxB] = imag[idxA] - tImag; real[idxA] += tReal; imag[idxA] += tImag;

12. Engenharia: Integração de Fourier

13 / 20

O arquivo \texttt{analyzer.js} calcula os coeficientes da Série ($a_n, b_n$) aplicando a \textbf{Regra dos Trapézios}.

A área sob a curva é integrada multiplicando o som pelas funções ortogonais.

for (let n = 1; n <= numHarmonics; n++) { let an = 0, bn = 0; for (let i = 0; i < periodSamples; i++) { const t = i / sampleRate; const omega = 2 * Math.PI * n * fundamentalHz * t; an += samples[i] * Math.cos(omega); // a_n bn += samples[i] * Math.sin(omega); // b_n } an = (2 / periodSamples) * an; bn = (2 / periodSamples) * bn; }
