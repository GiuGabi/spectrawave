1. Introdução ao SpectraWave

02 / 20

O projeto SpectraWave surge como uma ferramenta analítica computacional desenvolvida nativamente para navegadores web.

Nosso propósito central é demonstrar ao vivo como o sistema recebe um sinal mecânico ondulatório complexo, isola suas regiões de máxima densidade energética e realiza o mapeamento completo de seus componentes espectrais.

Abdicar de bibliotecas matemáticas de alto nível prontas (como SciPy) foi uma escolha de design: todo o Processamento Digital de Sinais (DSP) que vocês verão rodando foi escrito em \textit{Vanilla JavaScript} pelo grupo.

2. A Natureza do Som e Discretização

03 / 20

Fisicamente, o som consiste em oscilações de pressão. Ao inserirmos um áudio no sistema, o navegador executa a amostragem dessa variação milhares de vezes por segundo.

Isto gera um vetor bruto no Domínio do Tempo (o gráfico amarelo que exibiremos na interface).

Contudo, essa matriz de números não revela a "receita" do som. Precisamos de um prisma matemático para separar essa onda em frequências isoladas.

Representação do Vetor $x[n]$

// Estrutura do buffer de áudio decodificado const audioBuffer = audioCtx.decodeAudioData(arrayBuffer); const channelData = audioBuffer.getChannelData(0); // Vetor flutuante gerado: x[n] = [ 0.0012, 0.0154, 0.0892, -0.0413, ... ]

3. A Série de Fourier Contínua

04 / 20

A premissa matemática é que qualquer oscilação periódica pode ser recriada somando-se infinitas ondas puras de senos e cossenos. A equação trigonométrica base é:

$$f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left[ a_n \cos(2\pi n f_0 t) + b_n \sin(2\pi n f_0 t) \right]$$

O SpectraWave resolve esta equação dinamicamente para gerar a expansão analítica que aparece na última seção da nossa interface.

4. Elementos da Equação Contínua

05 / 20

Dissecando os termos que o nosso sistema calcula na prática:

  • Componente DC ($\frac{a_0}{2}$): A média aritmética do sinal, indicando se a onda flutua simetricamente no eixo zero ou se sofre um desvio (tensão contínua).
  • Freq. Fundamental ($f_0$): A taxa de oscilação mais baixa que o nosso motor detecta.
  • Coeficientes ($a_n$ e $b_n$): Os multiplicadores de "volume" de cada componente ortogonal necessários para reconstruir o sinal perfeito.

5. Transformada Discreta de Fourier (DFT)

06 / 20

A Série de Fourier teórica exige um sinal infinito. Na computação do SpectraWave, operamos matrizes finitas de $N$ amostras discretas.

Para isso, convertemos as amostras temporais $x[n]$ no vetor complexo de frequências $X[k]$ utilizando a equação clássica da DFT:

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-i \frac{2\pi k n}{N}}$$

6. Identidade de Euler e Rotação

07 / 20

A mágica do algoritmo ocorre ao expandirmos a exponencial complexa pela Identidade de Euler ($e^{-i\theta} = \cos\theta - i\sin\theta$), quebrando a equação em componentes cartesianas reais e imaginárias:

$$X[k] = \underbrace{\sum_{n=0}^{N-1} x[n] \cos\left(\frac{2\pi k n}{N}\right)}_{\text{Eixo Real (a)}} - i \underbrace{\sum_{n=0}^{N-1} x[n] \sin\left(\frac{2\pi k n}{N}\right)}_{\text{Eixo Imaginário (b)}}$$

O sistema essencialmente multiplica a onda bruta por ondas de teste na frequência investigada $k$.

7. A Intuição Geométrica

08 / 20

A DFT é um "enrolamento" gráfico da onda sonora ao redor de um círculo polar com velocidade de rotação ajustável $k$.

  • Se a frequência do áudio não coincidir com a velocidade $k$, o somatório se anula na origem.
  • Se houver ressonância matemática, as cristas da onda puxam o centro de massa do círculo para longe do centro.

Vetor Complexo Resultante

$$X[k] = a + bi$$

Coordenada que define o pico de ressonância.

8. Magnitude e Fase Espectral

09 / 20

A partir das coordenadas cartesianas ($a$ e $b$) geradas pelo código, extraímos as propriedades físicas da acústica que são plotadas no site:

$$\text{Magnitude (Força)} = |X[k]| = \sqrt{a^2 + b^2}$$
$$\text{Fase (Atraso)} = \phi_k = \arctan\left(\frac{b}{a}\right)$$

O resultado é convertido para a notação polar elegante: $X[k] = |X|e^{i\phi}$.

11. Engenharia: Estágio de Borboletas

12 / 20

Após a reordenação, o algoritmo executa o \textit{Butterfly Stage}.

Realizamos as multiplicações complexas rotacionando as fatias de dados por fatores de giro (senos e cossenos), derrubando a complexidade para $O(N \log N)$.

// Multiplicação complexa implementada "na raça" const tReal = wReal * real[idxB] - wImag * imag[idxB]; const tImag = wReal * imag[idxB] + wImag * real[idxB]; // Combinação Linear Radix-2 real[idxB] = real[idxA] - tReal; imag[idxB] = imag[idxA] - tImag; real[idxA] += tReal; imag[idxA] += tImag;

12. Engenharia: Integração de Fourier

13 / 20

Para construir as tabelas da seção final, o \texttt{analyzer.js} faz a integração pela \textbf{Regra dos Trapézios}.

O áudio $x[t]$ é multiplicado pela base ortogonal ($\cos(\omega t)$ e $\sin(\omega t)$) num \texttt{loop} de amostragem contínua.

for (let n = 1; n <= numHarmonics; n++) { let an = 0, bn = 0; for (let i = 0; i < periodSamples; i++) { const t = i / sampleRate; const omega = 2 * Math.PI * n * fundamentalHz * t; an += samples[i] * Math.cos(omega); // Componente Cosseno bn += samples[i] * Math.sin(omega); // Componente Seno } an = (2 / periodSamples) * an; bn = (2 / periodSamples) * bn; }

15. Dissecação das Métricas Numéricas

16 / 20

Como visualizamos no Painel de Métricas gerado pela plataforma, as grandezas acústicas foram calculadas rigorosamente:

  • Amostragem ($f_s$): O sistema leu o fluxo a $48.000\text{ Hz}$. A onda foi fatiada 48 mil vezes em um único segundo.
  • Nyquist ($f_s/2$): O limite máximo de resolução sem erro de \textit{aliasing} é de $24.000\text{ Hz}$.
  • Resolução Espectral ($\Delta f$): Como alocamos nossa FFT com $N=32768$ elementos de vetor, calculamos a separação térmica exata por compartimento:
    $\Delta f = \frac{48000}{32768} = 1.46\text{ Hz}$
